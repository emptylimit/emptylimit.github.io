Coinduction

Written by: Gabriel Field.

Introduction

We aim to give a simple introduction to coinductive types and how to prove equality statements on them. We assume the reader is familiar with inductive types[1] [1] Also known as "algebraic data types" in some programming languages.. This article is programming-language agnostic, but we will write code in a Haskell-ish way when code is required. This article will include many exercises and proofs. They are all within reach; try to do them without having them spoiling them first!

This article is designed to be read linearly. Later sections depend on prior ones in essential ways, so skipping ahead may leave the reader confused.

Throughout, $0$ denotes either the number $0$ or the empty set, and $1 := \{0\}$ denotes the singleton set. The operator $+$ is used for disjoint union of sets and for addition of numbers.

Initial Algebras and Inductive Types: The Intuition and Construction

Coinductive types are dual to inductive types, so we first present a categorical view on induction.

Definition. (Algebra)

Fix an endofunctor $T : \mathsf{C} \to \mathsf{C}$ on a category $\mathsf{C}$. An algebra for $T$ consists of:

  • An object $a \in \mathsf{C}$;
  • An arrow $\alpha : T\ a \to a$ in $\mathsf{C}$.

A morphism from an algebra $T\ a \xrightarrow{\alpha} a$ to another algebra $T\ b \xrightarrow{\beta} b$ is a map $f : a \to b$ in $\mathsf{C}$ such that

commutes.

Lemma. (Algebras form a category)

The algebras for an endofunctor $T : \mathsf{C} \to \mathsf{C}$ form a category, equipped with identity arrows $1_{T\ a \xrightarrow{\alpha} a} := 1_a$ and with composition of morphisms given by composition in $\mathsf{C}$.

Consider an algebra $T\ A \xrightarrow{\alpha} A$ for an endofunctor $T : \mathbf{Set} \to \mathbf{Set}$. To a programmer, the set $A$ may be the type of some data of interest. The map $\alpha : T\ A \to A$ describes how to form data of that type, given other data from a transformed data type $T\ A$.

Example.

Specialise $T : X \mapsto 1 + X$. An algebra $T\ A \xrightarrow{\alpha} A$ consists of two maps $1 \xrightarrow{x_0} A$ and $A \xrightarrow{u} A$; an element $x_0 \in A$ and a function $u$ to "update" an element of $A$ into another one. A famously chaotic example involves setting $A := [0, 1]$ and $u := x \mapsto 2x \bmod 1$. For various values of $x_0$, the sequences $x_{i + 1} := u (x_i)$ behave vastly differently.

The functional programmer may see this as a setting to describe recursive functions. The transformed type $T\ A$ describes the input to a recursive function — in the $T\ A = 1 + A$ case, it is either a "base case" $0 \in 1$ or a "recursive input" from $A$ — and the function $\alpha$ evaluates its input. The previous example illustrates this. However, one must take care to define recursive functions to ensure they always terminate.

A particularly "nice" type for recursion using $T$ would be one which is "completely defined using this kind of recursion" in the following sense. Consider forming a chain $$\begin{align*} &0 \xrightarrow{!} T\ 0 \xrightarrow{T\ !} T^2\ 0 \xrightarrow{T^2\ !} T^3\ 0 \xrightarrow{T^3\ !} \cdots \end{align*}$$ where $! : 0 \to T\ 0$ is the unique map recognising that the empty set is a subset of $T\ 0$. One can think of this as "starting with nothing, and freely adding elements that $T$ requires". In our example, we have $$\begin{align*} &\varnothing \subseteq 1 + \varnothing \subseteq 1 + (1 + \varnothing) \subseteq 1 + (1 + (1 + \varnothing)) \subseteq \cdots \\ \text{up to isomorphism:}\quad &\varnothing \subseteq \varnothing \cup \{0\} \subseteq \varnothing \cup \{0\} \cup \{1\} \subseteq \varnothing \cup \{0\} \cup \{1\} \cup \{2\} \subseteq \cdots \\ \text{equivalently:}\quad &\varnothing \subseteq \{0\} \subseteq \{0, 1\} \subseteq \{0, 1, 2\} \subseteq \cdots \end{align*}$$ Taking the colimit of this diagram, which in our example corresponds to taking the union of these nested sets, we arrive at the desired type. In our example, we do indeed have a natural map $T\left( \mathrm{colim}_{i \in \omega} T^i 0 \right) \to \mathrm{colim}_{i \in \omega} T^i 0$ to make this into an algebra; it is the map $1 + \mathbb{N} \to \mathbb{N}$ given by $1 \to \mathbb{N}$ picking out the element $0$, and $\mathbb{N} \to \mathbb{N}$ taking the successor of a natural number. The functional programmer would recognise these as the two constructors for the inductive type $\mathbb{N}$, and immediately recall the following recursion principle:

Recursion principle for $\mathbb{N}$.

Fix a type $X$. To define a function $f : \mathbb{N} \to X$, one needs only define a value $x_0 \in X$ to represent $f\ 0$ and a function $u : X \to X$ to update a value $f\ n$ to the value of its successor $f\ (\texttt{Succ}\ n)$. The defined function then satisfies:

  • $f\ 0 = x_0$;
  • $f\ (\texttt{Succ}\ n) = u\ (f\ n)$ for all $n \in \mathbb{N}$;

and is the unique function with these properties.

The categorical framework is illuminating here. Foremost, the value $x_0 \in X$ and $u : X \to X$ together define an algebra $1 + X \xrightarrow{\alpha} X$ for $T$. Next, the requirements on $f$ say exactly that it is an algebra morphism; i.e. the diagram

commutes. Taken together, the recursion principle is exactly the statement that $1 + \mathbb{N} \xrightarrow{(0, \texttt{Succ})} \mathbb{N}$ is an initial algebra for $T$.

Definition. (Initial algebra)

An initial algebra for an endofunctor $T : \mathsf{C} \to \mathsf{C}$ is an initial object in the category of algebras for $T$. Explicitly, it consists of an object $i \in \mathsf{C}$ and an arrow $T\ i \xrightarrow{\text{cons}} i$ in $\mathsf{C}$ with the following universal property: for any other object $a \in \mathsf{C}$ and map $T\ a \xrightarrow{\alpha} a$, there is a unique map $f : i \to a$ such that

commutes.

In type theory and various programming languages, an initial algebra for a polynomial endofunctor $T : \mathbf{Type} \to \mathbf{Type}$ is often called its associated inductive type or algebraic data type. The map $\text{cons} : T\ i \to i$ can be thought of as providing the constructors for this type.

Initial Algebras and Induction: The Results

As the programmer would hope, initial algebras are uniquely determined.

Remark. (Initial algebras are uniquely determined)

Up to isomorphism of algebras, each endofunctor $T : \mathsf{C} \to \mathsf{C}$ has at most one initial algebra. That is, any two initial algebras $T\ i \xrightarrow{ι} i$ and $T\ i' \xrightarrow{ι'} i'$ share a unique isomorphism $f : i \simeq j$ for which $f \circ ι = ι' \circ T\ f$.

The proof is trivial: initial objects in any category are uniquely determined.

The constructors $(0, \texttt{Succ}) : 1 + \mathbb{N} \to \mathbb{N}$ are a bijection. This is not a coincidence:

Lemma. (Constructors are isomorphisms)

Let $T\ i \xrightarrow{\text{cons}} i$ be the initial algebra for an endofunctor $T : \mathsf{C} \to \mathsf{C}$. Then, $\text{cons} : T i \simeq i$ is an isomorphism in $\mathsf{C}$.

Example.

The constructors $(0, \texttt{Succ}) : 1 + \mathbb{N} \simeq \mathbb{N}$ express that every natural number is either zero or the successor of another natural number.

The natural numbers $\mathbb{N}$ famously come with an induction principle: to establish that a subset $A \subseteq \mathbb{N}$ is in fact all of $\mathbb{N}$, one proves that $0 \in A$ and $A$ is closed under $\text{Succ}$. In our framework, this is to say that the constructors $(0, \text{Succ})$ form an algebra on $A$. Taking a more categorical focus, it is to say that we have an algebra structure $1 + A \xrightarrow{\alpha} A$ which is a sub-object of $\mathbb{N}$ (in the category of algebras); i.e. we have an injection $ι : A \hookrightarrow \mathbb{N}$ such that

commutes. In this language, the induction principle states that $\mathbb{N}$ has no proper subalgebras. This generalises:

Lemma. (Initial objects have no proper subobjects)

Let $i$ be the initial object in a category $\mathsf{C}$, and let $ι : a \rightarrowtail i$ be a monomorphism into $i$. Then, $ι$ is an isomorphism in $\mathsf{C}$.

Example.

Take $\mathsf{C}$ in the previous lemma to be the category of algebras for upcoming choices of endofunctors $T : \mathbf{Set} \to \mathbf{Set}$. The initial object $i$ in the previous lemma will then be the associated initial algebra for $T$.

  • For $T : X \mapsto 1 + X$, the lemma recovers the induction principle of $\mathbb{N}$ described before. Identifying a subset $X \subseteq \mathbb{N}$ with its predicate $P : \mathbb{N} \to \texttt{Bool}$ (which assigns $\texttt{true}$ to the elements of $X$ and $\texttt{false}$ to everything in $\mathbb{N} \setminus X$), we get the more familiar induction rule: to prove $∀ n \in \mathbb{N},\, P\ n$, we need only prove $P\ 0$ and $∀ n \in \mathbb{N},\, P\ n \implies P\ (\texttt{Succ}\ n)$.
  • For $T : X \mapsto 1 + A \times X$ (with $A$ a fixed set), the lemma recovers the induction principle of its initial algebra $\texttt{List}\ A$. Translating from subsets of $\texttt{List}\ A$ to characteristic predicates $P : \mathbb{N} \to \texttt{Bool}$, we have the familiar structural induction rule: to prove $∀ \mathrm{xs} \in \texttt{List}\ A,\, P\ \mathrm{xs}$, we need only prove $P\ []$ and $∀ \mathrm{xs} \in \texttt{List}\ A, ∀ a \in {A},\, P\ \mathrm{xs} \implies P\ (a :: \mathrm{xs})$.

The previous lemma has another use case which will seem trivial now, but will be a key example when we move to explain coinduction. It can be used to prove that two maps out from an initial algebra are equal, even if the target is not equipped with an algebra structure.

Lemma. (Simple inductive rule for proving that maps out of initial algebras are equal)

Let $T\ i \xrightarrow{\texttt{cons}} i$ be the initial algebra for an endofunctor $T : \mathsf{C} \to \mathsf{C}$ and let $f, g : i \to a$ be parallel arrows out of $i$. Suppose that the equaliser $ι : e \rightarrowtail i$ of $f$ and $g$ exists in $\mathsf{C}$. Then, if $f \circ \texttt{cons} \circ T\ ι = g \circ \texttt{cons} \circ T\ ι$, we must have $f = g$.

Note that $a$ is not required to have an algebra structure $T\ a \to a$.

We stress that induction is not the only way to prove results about initial algebras.

In the previous section, we gave a construction of inductive types which worked for every stated exercise. Unfortunately, this construction does not always work. Under the following circumstances, it does:

Theorem. (Adámek's fixed point theorem)

Let $T : \mathsf{C} \to \mathsf{C}$ be an endofunctor. Suppose that $\mathsf{C}$ contains an initial object $0$ and the colimit of the sequence $$\begin{align*} 0 \xrightarrow{!} T\ 0 \xrightarrow{T !} T^2\ 0 \xrightarrow{T^2 !} T^3\ 0 \xrightarrow{T^3 !} \cdots \end{align*}$$ and suppose furthermore that $T$ preserves this colimit. Then, the composite isomorphism $T(\mathrm{colim}_{i \in \omega} T^i 0) \simeq \mathrm{colim}_{i \in \omega} T^{i + 1} 0 \simeq \mathrm{colim}_{i \in \omega} T^i 0$ gives $\mathrm{colim}_{i \in \omega} T^i 0$ an algebra structure for $T$. Furthermore, $T(\mathrm{colim}_{i \in \omega} T^i 0) \simeq \mathrm{colim}_{i \in \omega} T^i 0$ is an initial algebra.

The statement of this result was adapted from this nLab article.

One can think of this result as constructing the initial algebra by looking at how the various recursively constructed $T^i 0$ "sit inside" one another, and "closing the gaps $T^i 0 \to T^{i + 1} 0$ at infinity"[3] [3] The same idea appears in the proof of Theorem 5.6.12 in Category Theory in Context.. The assumption that $T$ preserves the constructed colimit can be thought of as a "finiteness" condition on $T$.

Terminal Coalgebras and Coinductive Types: A First Example

As with any abstract nonsense, our discussion thus far can be dualised, yielding coalgebras, corecursion and coinduction. In this section, we will construct the conatural numbers, dual to the natural numbers.

Definition. (Coalgebra)

Fix an endofunctor $T : \mathsf{C} \to \mathsf{C}$. A coalgebra for $T$ is an algebra in $\mathsf{C}^{\mathrm{op}}$ for $T : \mathsf{C}^{\mathrm{op}} \to \mathsf{C}^{\mathrm{op}}$. Explicitly, it consists of:

  • An object $a \in \mathsf{C}$;
  • An arrow $\alpha : a \to T\ a$ in $\mathsf{C}$.

A morphism from a coalgebra $a \xrightarrow{\alpha} T\ a$ to another coalgebra $b \xrightarrow{\beta} T\ b$ is a map $f : a \to b$ in $\mathsf{C}$ such that

commutes. Equivalently, it is a morphism from the algebra $T\ b \xrightarrow{\beta} b$ in $\mathsf{C}^{\mathrm{op}}$ to the algebra $T\ a \xrightarrow{\alpha} a$ in $\mathsf{C}^{\mathrm{op}}$.

Exercise. (Coalgebras form a category)

Dualise the relevant lemma to show that coalgebras form a category. What are the identity morphisms and composites?

An algebra $A \xrightarrow{\alpha} T\ A$ for an endofunctor $T : \mathbf{Set} \to \mathbf{Set}$ can be thought of programmatically as follows. The set $A$ represents a data type of interest, and $T\ A$ represents a different type of "observations" that could be made about $A$. The map $\alpha : A \to T\ A$ specifies a way of observing $A$ in $T\ A$. By continually applying $\alpha$ to the occurances of $A$ which appear in $T\ A$, one could form a chain of observations $$\begin{align*} A \xrightarrow{\alpha} T\ A \xrightarrow{T\ \alpha} T^2\ A \xrightarrow{T^2\ \alpha} T^3\ A \xrightarrow{T^3\ \alpha} \cdots \end{align*}$$ which could be interpreted as describing the "evolution" of a starting element of $A$ over time.

Example.

Specialise to $T : X \mapsto \{\text{no}\} + X$ (here $\text{no}$ is a special symbol, whose name will be useful later). Let $V$ be the vertex set of a maze, equipped with a special vertex $v_{\text{exit}}$ marking the exit of the maze. We can model a simple strategy for solving the maze as follows. Construct a function $\alpha : V \to T\ V$ by setting $\alpha\ v_{\text{exit}} := \text{no}$, and letting $\alpha\ v$ be any element of $V$ with an edge connecting $v$ to $\alpha\ v$, for $v \neq v_{\text{exit}}$. A strategy of this kind has no memory. From a starting vertex $v_{0} \in V$, the trace $$\begin{align*} v_{0} \in V \xrightarrow{\alpha} \{\text{no}\} + V \xrightarrow{T\ \alpha} \{\text{no}\} + (\{\text{no}\} + V) \xrightarrow{T^2\ \alpha} \{\text{no}\} + (\{\text{no}\} + (\{\text{no}\} + V)) \xrightarrow{T^3\ \alpha} \cdots \end{align*}$$ illustrates how this strategy evolves over time. If $\alpha$ finds $v_{\text{end}}$ from $v_{\text{start}}$ in exactly two moves, we would have $$\begin{align*} v_{0} \mapsto \texttt{Right}\ v_1 \mapsto \texttt{Right}\ (\texttt{Right}\ v_{\text{end}}) \mapsto \texttt{Left}\ \text{no} \mapsto \texttt{Right}\ (\texttt{Left}\ \text{no}) \mapsto \texttt{Right}\ (\texttt{Right}\ (\texttt{Left}\ \text{no})) \mapsto \cdots \end{align*}$$ We can re-cast this as follows. The sequence $V \to \{\text{no}\} + V \to \cdots$ of sets is isomorphic to a sequence $$\begin{align*} V \to \{0\} + V \to \{0, 1\} + V \to \{0, 1, 2\} + V \to \{0, 1, 2, 3\} + V \to \cdots \end{align*}$$ The first arrow sends $v \in V$ to $\texttt{Left}\ 0$ if $v = v_{\text{end}}$, or to $\texttt{Right}\ (\alpha\ v)$ otherwise. The second arrow maps $\texttt{Left}\ 0$ to $\texttt{Left}\ 0$, it maps $\texttt{Right}\ v_{\text{end}}$ to $\texttt{Left}\ 1$, and it maps $\texttt{Right}\ v$ to $\texttt{Right}\ (\alpha\ v)$ for $v \neq v_{\text{end}}$. The third arrow operates similarly, sending $\texttt{Left}\ i$ to $\texttt{Left}\ i$, sending $\texttt{Right}\ v_{\text{end}}$ to $\texttt{Left}\ 2$, and sending $\texttt{Right}\ v$ to $\texttt{Right}\ (\alpha\ v)$ for $v \neq v_{\text{end}}$; etc. In this light, the evolution of our starting vertex $v_0$ would be $$\begin{align*} v_0 \mapsto \texttt{Right}\ v_1 \mapsto \texttt{Right}\ v_{\text{end}} \mapsto \texttt{Left}\ 2 \mapsto \texttt{Left}\ 2 \mapsto \texttt{Left}\ 2 \mapsto \cdots \end{align*}$$ The "settled down" part of the sequence $\texttt{Left}\ 2 \mapsto \cdots$ identifies that $\alpha$ found the exit at index $2$ in the sequence. If $\alpha$ never finds the exit (i.e. if the strategy gets caught in a cycle of the maze), we instead see a trace $$\begin{align*} v_0 \mapsto \texttt{Right}\ v_1 \mapsto \texttt{Right}\ v_2 \mapsto \texttt{Right}\ v_3 \mapsto \texttt{Right}\ v_4 \mapsto \cdots \end{align*}$$ There is no "settled down" or "terminated" part of this sequence.

Let's turn our attention to terminal coalgebras.

Definition. (Terminal coalgebra)

A terminal coalgebra for an endofunctor $T : \mathsf{C} \to \mathsf{C}$ is a terminal object in the category of coalgebras for $T$. Explicitly, it consists of an object $j \in \mathsf{C}$ and an arrow $j \xrightarrow{\texttt{des}} T\ j$ with the following universal property: for any other object $a \in \mathsf{C}$ and map $a \xrightarrow{\alpha} T\ a$, there is a unique map $f : a \to j$ such that

We saw that the initial algebra for $T : X \mapsto 1 + X$ is the natural numbers with their constructors $1 + \mathbb{N} \xrightarrow{(0, \texttt{Succ})} \mathbb{N}$. This algebra measures the depth of recursive computations of algebras $1 + A \to A$, and is "freely generated by recursion". One could guess that the dual terminal coalgebra for $T$ would measure the length of a continual evolution along a coalgebra $A \to \{\text{no}\} + A$. In fact, the dual construction to Adámek's fixed point theorem works for this terminal coalgebra.

Example. (Constructing the conatural numbers)

Dual to the natural numbers, the terminal coalgebra for $T : X \mapsto \{\text{no}\} + X$ is known as the set of conatural numbers. Let $?$ be a symbol not appearing in $\mathbb{N}$. The conatural numbers can be constructed as the limit of the sequence $$ \begin{array}{lllllllllll} & &\cdots & \xrightarrow{T^3\ !} & T^3\ \{?\} & \xrightarrow{T^2\ !} & T^2\ \{?\} & \xrightarrow{T\ !} & T\ \{?\} & \xrightarrow{!} & \{?\} \\ = & &\cdots & \longrightarrow & \{\text{no}\} + (\{\text{no}\} + (\{\text{no}\} + \{?\})) & \longrightarrow & \{\text{no}\} + (\{\text{no}\} + \{?\}) & \longrightarrow & \{\text{no}\} + \{?\} & \longrightarrow & \{?\} \\ \simeq & &\cdots & \longrightarrow & \{2\} + (\{1\} + (\{0\} + \{?\})) & \longrightarrow & \{1\} + (\{0\} + \{?\}) & \longrightarrow & \{0\} + \{?\} & \longrightarrow & \{?\} \\ \simeq & &\cdots & \longrightarrow & \{2, 1, 0\} + \{?\} & \longrightarrow & \{1, 0\} + \{?\} & \longrightarrow & \{0\} + \{?\} & \longrightarrow & \{?\} \end{array} $$ In the bottom sequence, the final arrow is the unique map $\{0\} + \{?\} \to \{?\}$, which sends $\texttt{Left}\ 0 \mapsto {?}$ and $\texttt{Right}\ ? \mapsto {?}$. The second-last arrow is the map which sends $\texttt{Left}\ 1 \mapsto \texttt{Left}\ 0$ and maps the other two values to $\texttt{Right}\ ?$. The third-last arrow maps $\texttt{Left}\ 2 \mapsto \texttt{Left}\ 1$, maps $\texttt{Left}\ 1 \mapsto \texttt{Left}\ 0$, and maps the other two values to $\texttt{Right}\ ?$.

The limit of the bottom sequence is the set $$ \lim_{i \in \omega^{\mathrm{op}}} T^i \{?\} \simeq \left\{ \left( \dots, x_2, x_1, x_0 \right) \;\middle\vert\; \text{each } x_i \in \{i - 1, \dots, 0\} + \{?\} \text{ and each } x_{i + 1} \mapsto x_i \text{ in the sequence} \right\} $$ and the limit cone consists of the projection maps onto each $x_i \in \{i - 1, \dots, 0\} + \{?\}$. For example, the limit contains the following elements: $$\begin{align*} (\dots, 3, 2, 1, 0, ?) && (\dots, 2, 1, 0, ?, ?) && (\dots, 1, 0, ?, ?, ?) && (\dots, 0, ?, ?, ?, ?) \end{align*}$$ We can think of these elements as starting on the right with a "play token" $`?\text{'}$, and moving left. Whenever we have a $`?\text{'}$ token, we can choose to swap it out for a $0$ (and thereafter begin counting up), or to retain the $`?\text{'}$ token. There is also a special element $$\begin{align*} (\dots, ?, ?, ?, ?, ?) \end{align*}$$ given by always choosing to retain the token. This suggests a bijection $$\begin{align*} (\dots, 3, 2, 1, 0, ?) &\leftrightarrow 0 , & (\dots, 2, 1, 0, ?, ?) &\leftrightarrow 1, & (\dots, 1, 0, ?, ?, ?) &\leftrightarrow 2, & \cdots & , & (\dots, ?, ?, ?, ?, ?) &\leftrightarrow \infty \end{align*}$$ which assigns to an element of the limit to the index, counted from the right, of its last $`?\text{'}$ token. This bijection identifies the limit $$\begin{align*} \lim_{i \in \omega^{\mathrm{op}}} T^i \{?\} \simeq \mathrm{co}\mathbb{N} := \mathbb{N} + \{\infty\} \end{align*}$$ with the set of conatural numbers.

The dual to Adámek's fixed point theorem asserts that this construction forms the terminal coalgebra of $T$ so long as $T$ preserves this limit. Indeed, the function $$\begin{align*} \mathrm{pred} : \mathrm{co}\mathbb{N} &\longrightarrow \{\text{no}\} + \mathrm{co}\mathbb{N} \\ 0 &\longmapsto \text{no} \\ n + 1 &\longmapsto n \\ \infty &\longmapsto \infty \end{align*}$$ which maps a conatural number to its predecessor is an isomorphism. Some careful checking, left as an exercise to the reader, that this map commutes with the relevant limit cones indeed verifies that $T$ preserves the limit. Therefore $\mathrm{co}\mathbb{N} \xrightarrow{\mathrm{pred}} \{\text{no}\} + \mathrm{co}\mathbb{N}$ is the coalgebra of $T : X \mapsto \{\text{no}\} + X$.

We saw previously that the recursion principle for the natural numbers was encoded by the fact that $1 + \mathbb{N} \xrightarrow{(0, \texttt{Succ})} \mathbb{N}$ is an initial algebra for $X \mapsto 1 + X$. Duality allows us to define a corecursion principle for the conatural numbers, useful for constructing maps into $\mathrm{co}\mathbb{N}$.

Corecursion principle for $\mathrm{co}\mathbb{N}$.

Let $A$ be a set. To define a function $f : A \to \mathrm{co}\mathbb{N}$, it suffices to define a map $\alpha : A \to \{\text{no}\} + A$. The defined map $f$ is the unique function $A \to \mathrm{co}\mathbb{N}$ such that

commutes; i.e. $$\begin{align*} \mathrm{pred}\ (f\ a) &= \texttt{case}\ \alpha\ a\ \texttt{of} \\ &\quad\quad \texttt{Left}\ \text{no} \to \texttt{Left}\ \text{no} \\ &\quad\quad \texttt{Right}\ b \to \texttt{Right}\ (f\ b) \end{align*}$$ for all $a \in A$. Importantly, the only way to have $\mathrm{pred}\ (f\ a) = \text{no}$ is to have $\alpha\ a = \text{no}$.

When we wish to define a function into $\mathrm{co}\mathbb{N}$ corecursively in this article, we will write $f := \texttt{corec}\ \alpha$. A Haskell implementation of $\texttt{corec}$ is $$\begin{align*} &\texttt{corec} :: (A \to \texttt{Either}\ \{\text{no}\}\ A) \to A \to \mathrm{co}\mathbb{N} \\ &\texttt{corec}\ \alpha\ a = \\ &\quad\quad\texttt{case}\ \alpha\ a\ \texttt{of} \\ &\quad\quad\quad\quad \texttt{Left}\ \text{no} \to 0 \\ &\quad\quad\quad\quad \texttt{Right}\ b \to \texttt{Right}\ (\texttt{Succ}\ (f\ b)) \end{align*}$$ where, thanks to Haskell's laziness, one may use the type $\texttt{data CoNat = Zero } \vert\ \texttt{ Succ\ CoNat}$ in place of $\mathrm{co}\mathbb{N}$ (albeit computation of the term $\infty$ will never terminate).

Example. (Defining $0 \in \mathrm{co}\mathbb{N}$ corecursively)

The element $\texttt{Zero} \in \mathrm{co}\mathbb{N}$ is given by $\texttt{Zero} := \texttt{corec}\ (\lambda\ \texttt{\textunderscore} \to \text{no})\ 0$. In the above diagram, we have taken $\alpha : 1 \to \{\text{no}\} + 1$ by setting $\alpha\ 0 := \text{no}$. We will henceforth write $0$ instead of $\texttt{Zero}$.

Exercise.

Example. (Defining $\infty \in \mathrm{co}\mathbb{N}$ corecursively)

The only other choice for a function $\alpha : 1 \to \{\text{no}\} + 1$ is given by setting $\alpha\ 0 := 0$. The element $x := \texttt{corec}\ (\lambda\ \texttt{\textunderscore} \to 0)\ 0$ of $\mathrm{co}\mathbb{N}$ is the unique element satisfying $\mathrm{pred}\ x = x$, which is $x = \infty$.

We saw earlier that $\mathrm{co}\mathbb{N} = \mathbb{N} + \{\infty\}$, and have been able to construct the elements $0, \infty \in \mathrm{co}\mathbb{N}$. We now show how to corecursively identify all the elements of $\mathrm{co}\mathbb{N}$ which lie in $\mathrm{co}\mathbb{N}$.

Exercise. (Identifying $\mathbb{N}$ within $\mathrm{co}\mathbb{N}$)

The constructors of $\mathbb{N}$ are a bijection $(0, \texttt{Succ}) : 1 + \mathbb{N} \simeq \mathbb{N}$, whose inverse is the predecessor map $\mathrm{pred} : \mathbb{N} \to \{\text{no}\} + \mathbb{N}$ (with $\mathrm{pred}\ 0 := \text{no}$). Define $ι : \mathbb{N} \to \mathrm{co}\mathbb{N}$ by $ι := \texttt{corec}\ \mathrm{pred}$. Show that $ι$ is an injection, and it maps the elements of $\mathbb{N}$ to the corresponding elements of $\mathrm{co}\mathbb{N}$ (i.e. $\mathrm{pred}\ (ι\ 0) = \text{no}$, $\mathrm{pred}\ (ι\ 1) = 0$, $\mathrm{pred}\ (ι\ 2) = 1$, etc.).

To conclude this section, we return to our example on using coalgebras for $X \mapsto \{\text{no}\} + X$ to model memoryless maze-solving strategies. We saw that a strategy $\alpha : V \to \{\text{no}\} + V$ generates a chain $$\begin{align*} V \longrightarrow \{0\} + V \longrightarrow \{0, 1\} + V \longrightarrow \{0, 1, 2\} + V \longrightarrow \{0, 1, 2, 3\} + V \longrightarrow \cdots \end{align*}$$ and various starting vertices $u_0, v_0, w_0 \in V$ evolved through the chain, perhaps arriving at the exit vertex $v_{\text{exit}}$: $$ \begin{array}{ccccccccc} V & \longrightarrow & \{0\} + V & \longrightarrow & \{0, 1\} + V & \longrightarrow & \{0, 1, 2\} + V & \longrightarrow & \{0, 1, 2, 3\} + V & \longrightarrow & \cdots \\ u_0 = v_{\text{exit}} & \longmapsto & \texttt{Left}\ \text{no} & \longmapsto & \texttt{Left}\ \text{no} & \longmapsto & \texttt{Left}\ \text{no} & \longmapsto & \texttt{Left}\ \text{no} & \longmapsto & \cdots \\ v_0 & \longmapsto & \texttt{Right}\ v_1 & \longmapsto & \texttt{Right}\ v_{\text{exit}} & \longmapsto & \texttt{Left}\ \text{no} & \longmapsto & \texttt{Left}\ \text{no} & \longmapsto & \cdots \\ w_0 & \longmapsto & \texttt{Right}\ w_1 & \longmapsto & \texttt{Right}\ w_2 & \longmapsto & \texttt{Right}\ w_3 & \longmapsto & \texttt{Right}\ w_4 & \longmapsto & \cdots \end{array} $$

What is the corresponding function $f := \texttt{corec}\ \alpha : V \to \mathrm{co}\mathbb{N}$? For a chain $\cdots \xmapsto{\alpha} x_2 \xmapsto{\alpha} x_1 \xmapsto{\alpha} v_{\text{exit}} \xmapsto{\alpha} \text{no}$, we have $$\begin{align*} \begin{array}{lcccr} \alpha\ v_{\text{exit}} = \text{no} &\implies & \mathrm{pred}\ (f\ v_{\text{exit}}) = \text{no} &\implies & f\ v_{\text{exit}} = 0 \\ \alpha\ x_1 = v_{\text{exit}} &\implies & \mathrm{pred}\ (f\ x_1) = f\ v_{\text{exit}} = 0 & \implies & f\ x_1 = 1 \\ \alpha\ x_2 = x_1 & \implies & \mathrm{pred}\ (f\ x_2) = f\ x_1 = 1 & \implies & f\ x_2 = 2 \end{array} \end{align*}$$ which suggests that $f\ x_i = i$ measures the number of steps $\alpha$ takes to find the exit from the vertex $x_i$. For an endless chain $y_0 \xmapsto{\alpha} y_1 \xmapsto{\alpha} \cdots$ which never finds the exit, we must have $$\begin{align*} f\ y_0 \xmapsto{\mathrm{pred}} f\ y_1\ \textcolor{gray}{(\neq \text{no})} \xmapsto{\mathrm{pred}} f\ y_2\ \textcolor{gray}{(\neq \text{no})} \xmapsto{\mathrm{pred}} f\ y_2\ \textcolor{gray}{(\neq \text{no})} \xmapsto{\mathrm{pred}} \cdots \end{align*}$$ This implies that $f\ y_0 = f\ y_1 = \cdots = \infty$, also correctly measuring the number of steps which $\alpha$ takes to find the exit.

Terminal Coalgebras and Coinductive Types: Further Examples

The natural numbers measure the lengths of (finite) lists, where $1 + A \times \texttt{List}\ A \xrightarrow{([],\, (:))} \texttt{List}\ A$ is the initial algebra for $X \mapsto 1 + A \times X$ (for a fixed set $A$). In fact, $\mathbb{N} \simeq \texttt{List}\ 1$. We now generalise this, defining colists and investigating their relationship with the conatural numbers.

Definition. (Colists)

Fix a set $A$. The terminal coalgebra $\texttt{coList}\ A \xrightarrow{\mathrm{pop}} \{\text{no}\} + A \times (\texttt{coList}\ A)$ for $X \mapsto 1 + A \times X$ consists of the set $\texttt{coList}\ A$ of colists over $A$, together with the destructor $\mathrm{pop}$.

We can construct $\texttt{coList}\ A$ analogously to how we constructed $\mathrm{co}\mathbb{N}$. Tracing through the details, we find that[4] [4] We could have used round parentheses rather than square brackets here, but I've chosen to stick closer the Haskell list notation. $$\begin{align*} \texttt{coList}\ A := \left\{ [], [a_0], [a_0, a_1], \dots \;\middle\vert\; a_0, a_1, \dots \in A \right\} \cup \left\{ [a_0, a_1, \dots] \;\middle\vert\; a_0, a_1, \dots \in A \right\} \end{align*}$$ Thus, the set of colists over $A$ consists not only of the finite-length lists, but also the infinite streams $[a_0, a_1, \dots]$ over $A$.

The destructor $\mathrm{pop}$ acts by removing an element from the head of a colist, if possible. Explicitly, $$\begin{align*} & \mathrm{pop}\ [] := \text{no} \\ & \mathrm{pop}\ [a_0] := (a_0, []) \\ & \mathrm{pop}\ [a_0, a_1] := (a_0, [a_1]) \\ & \mathrm{pop}\ [a_0, a_1, a_2] := (a_0, [a_1, a_2]) \\ & \cdots \\ & \mathrm{pop}\ [a_0, a_1, a_2, \dots] := (a_0, [a_1, a_2, a_3, \dots]) \end{align*}$$ which has an evident Haskell implementation.

Constructing $\texttt{coList}\ A$.

We can play a similar game to construct $\texttt{coList}\ A$ as to our construction of $\mathrm{co}\mathbb{N}$. Elements of the limit of the sequence $$\begin{align*} \{?\} \longleftarrow \{\text{no}\} + A \times \{?\} \longleftarrow \{\text{no}\} + A \times (\{\text{no}\} + A \times \{?\}) \longleftarrow \{\text{no}\} + A \times (\{\text{no}\} + A \times (\{\text{no}\} + A \times \{?\})) \longleftarrow \cdots \end{align*}$$ can be thought of as sequences constructed as follows. The first element of the sequence is an initial "play token" $`?\text{'} \in \{?\}$. To get the next element of the sequence, spend the token and replace it with an element of $\{\text{no}\} + A \times \{?\}$; that is, yield either the value $\text{no}$, or a pair of an element $(a_0, {?}) \in A \times \{?\}$. If you no longer have a $`?\text{'}$ token (because you got the element $\text{no}$), then you have completed your sequence. If you still have a $`?\text{'}$ token (because you got a pair $(a_0, {?})$), then record the pair $a_0$ in your sequence, and play again. Here are some example elements of the limit constructed in this way (with $A := \left\{ \text{\textcolor{red}{red}}, \text{\textcolor{blue}{blue}} \right\}$): $$\begin{align*} &\left( {?}, \text{no} \right) \\ &\left( {?}, (\text{\textcolor{blue}{blue}}, {?}), \text{no} \right) \\ &\left( {?}, (\text{\textcolor{red}{red}}, {?}), (\text{\textcolor{blue}{blue}}, {?}), \text{no} \right) \\ &\left( {?}, (\text{\textcolor{red}{red}}, {?}), (\text{\textcolor{blue}{blue}}, {?}), (\text{\textcolor{red}{red}}, {?}), (\text{\textcolor{blue}{blue}}, {?}), \dots \right) \end{align*}$$ Hiding the $`?\text{'}$ tokens and the $\text{no}$'s, and swapping to square brackets, we get exactly the elements of $\texttt{coList}\ \left\{ \text{\textcolor{red}{red}}, \text{\textcolor{blue}{blue}} \right\}$ as described before: $$\begin{align*} & [] \\ & [ \text{\textcolor{blue}{blue}} ] \\ & [ \text{\textcolor{red}{red}}, \text{\textcolor{blue}{blue}} ] \\ & [ \text{\textcolor{red}{red}}, \text{\textcolor{blue}{blue}}, \text{\textcolor{red}{red}}, \text{\textcolor{blue}{blue}}, \dots ] \end{align*}$$

To summarise, an element of $\texttt{coList}\ A$ is a "continually evolving trace". One starts with a $`?\text{'}$ token and spends it to get an "observed value" in $\{\text{no}\} + A \times \{?\}$; any observed $?$ token must then be spent again, potentially ad infinitum, generating a sequence of observations. This interpretation generalises to construct elements of many terminal coalgebras.

As a terminal coalgebra, $\texttt{coList}\ A$ also has a corecursion principle.

Corecursion principle for $\texttt{coList}$.

Fix sets $A$ and $X$. To define a function $X \to \texttt{coList}\ A$, it suffices to define a map $\alpha : X \to \{\text{no}\} + A \times X$. The defined map $\texttt{corec}\ \alpha$ the unique function $X \to \texttt{coList}\ A$ such that

commutes; i.e. $$\begin{align*} & \mathrm{pop}\ (f\ x) = \texttt{case}\ \alpha\ x\ \texttt{of} \\ &\quad\quad\quad\quad\quad\quad \texttt{Left}\ \text{no} \to \texttt{Left}\ \text{no} \\ &\quad\quad\quad\quad\quad\quad \texttt{Right}\ (a, x') \to \texttt{Right}\ (a, f\ x') \end{align*}$$ for all $x \in X$.

The functions defined by this universal property assemble into a higher-order function $\texttt{corec} : (X \to \{\text{no}\} + A \times X) \to X \to \texttt{coList}\ A$.

Example. (Corecursive definitions of certain colists)

The empty colist $[] \in \texttt{coList}\ A$ is the unique colist with $\mathrm{pop}\ [] = \text{no}$. It can be defined by $[] := \texttt{corec}\ (\lambda\ \texttt{\textunderscore} \to \text{no})\ 0$; the lambda function has type $1 \to \{\text{no}\} + A \times 1$.

The only other choices of functions of type $1 \to \{\text{no}\} + A \times 1$ are the $\alpha_a := \lambda\ \texttt{\textunderscore} \to (a, 0)$, for each $a \in A$. The colists $\texttt{repeat}\ a := \texttt{corec}\ \alpha_a\ 0$ satisfy $\mathrm{pop}\ (\texttt{repeat}\ a) = (a, \texttt{repeat}\ a)$, which indicates that $\texttt{repeat}\ a = [a, a, \dots]$.

The list constructors $1 + A \times (\texttt{List}\ A) \xrightarrow{(0, \texttt{Succ})} \texttt{List}\ A$ are an isomorphism, with inverse $\mathrm{pop} : \texttt{List}\ A \to \{\text{no}\} + A \times (\texttt{List}\ A)$ giving a coalgebra. This defines a function $ι := \texttt{corec}\ \mathrm{pop} : \texttt{List}\ A \to \texttt{coList}\ A$ which recognises each list as a colist.

There are a number of familiar functions involving colists and conatural numbers which we can define corecursively. We will show how to reason about these corecursive definitions in the next section.

Example.

  • The function $\texttt{length} : \texttt{coList}\ A \to \mathrm{co}\mathbb{N}$ is defined using corecursion into $\mathrm{co}\mathbb{N}$ by $$\begin{align*} &\texttt{length} := \texttt{corec}\ (\lambda\ \mathrm{xs} \to \\ &\quad\quad\quad\quad\quad\quad \texttt{case}\ \mathrm{pop}\ \mathrm{xs}\ \texttt{of}\ \\ &\quad\quad\quad\quad\quad\quad\quad\quad \texttt{Left}\ \text{no} \to \texttt{Left}\ \text{no} \\ &\quad\quad\quad\quad\quad\quad\quad\quad \texttt{Right}\ (x, \mathrm{ys}) \to \texttt{Right}\ \mathrm{ys} ) \end{align*}$$
  • The function $\texttt{map} : (A \to B) \to \texttt{coList}\ A \to \texttt{coList}\ B$ is defined using corecursion into $\texttt{coList}\ B$ by $$\begin{align*} &\texttt{map}\ f := \texttt{corec}\ (\lambda\ \mathrm{as} \to \\ &\quad\quad\quad\quad\quad\quad \texttt{case}\ \mathrm{pop}\ \mathrm{as}\ \texttt{of}\ \\ &\quad\quad\quad\quad\quad\quad\quad\quad \texttt{Left}\ \text{no} \to \texttt{Left}\ \text{no} \\ &\quad\quad\quad\quad\quad\quad\quad\quad \texttt{Right}\ (a, \mathrm{as}') \to \texttt{Right}\ (f\ a, \mathrm{as}') ) \end{align*}$$
  • The function $\texttt{zip} : \texttt{coList}\ A \to \texttt{coList}\ B \to \texttt{coList}\ (A \times B)$ can be defined by instead defining the curried function $\texttt{zip}' : (\texttt{coList}\ A) \times (\texttt{coList}\ B) \to \texttt{coList}\ (A \times B)$ as follows: $$\begin{align*} &\texttt{zip}' := \texttt{corec}\ (\lambda\ (\mathrm{as}, \mathrm{bs}) \to \\ &\quad\quad\quad\quad\quad\quad \texttt{case}\ \mathrm{pop}\ \mathrm{as}, \mathrm{pop}\ \mathrm{bs}\ \texttt{of} \\ &\quad\quad\quad\quad\quad\quad\quad\quad \texttt{Right}\ (a, \mathrm{as}'),\ \texttt{Right}\ (b, \mathrm{bs}') \to ((a, b), (\mathrm{as}', \mathrm{bs}')) \\ &\quad\quad\quad\quad\quad\quad\quad\quad \texttt{\textunderscore}, \texttt{\textunderscore} \to \texttt{Left}\ \text{no} ) \end{align*}$$

An interesting terminal coalgebra with no interesting analogous initial algebra is the set of streams.

Definition.

Fix a set $A$. The terminal coalgebra $\texttt{Stream}\ A \xrightarrow{\mathrm{pop}} A \times (\texttt{Stream}\ A)$ for $X \mapsto A \times X$ consists of the set $\texttt{Stream}\ A$ of streams over $A$, together with the destructor $\mathrm{pop}$.

The streams are precisely the colists of infinite length. That is, $$\begin{align*} \texttt{Stream}\ A = \left\{ [a_0, a_1, \dots] \;\middle\vert\; a_0, a_1, \dots \in A \right\} \end{align*}$$

Whilst an element of $\texttt{Stream}\ A$ may be encoded by a mathematical function $\mathbb{N} \to A$, this is not a useful computational interpretation of this type. Rather, one should think of streams as "observed behaviours evolving over time"; only finitely much of the whole stream can ever be known at once.

Terminal Coalgebras and Coinduction: The Results

The results we have developed for initial algebras dualise. Here are a few such results.

Remark. (Terminal coalgebras are uniquely determined)

Up to isomorphism of coalgebras, each endofunctor has at most one terminal coalgebra.

Lemma. (Destructors are isomorphisms)

Let $j \xrightarrow{\texttt{des}} T\ j$ be the terminal coalgebra for an endofunctor $T : \mathsf{C} \to \mathsf{C}$. Then, $\texttt{des} : j \simeq T\ j$ is an isomorphism in $\mathsf{C}$.

Theorem. (Adámek's fixed point theorem, dual)

Let $T : \mathsf{C} \to \mathsf{C}$ be an endofunctor. Suppose that $\mathsf{C}$ contains a terminal object $1$ and the limit of the sequence $$\begin{align*} 1 \xleftarrow{!} T\ 1 \xleftarrow{T !} T^2\ 1 \xleftarrow{T^2 !} T^3\ 1 \xleftarrow{T^3 !} \cdots \end{align*}$$ and suppose furthermore that $T$ preserves this limit. Then, the composite isomorphism $\lim_{i \in \omega^{\mathrm{op}}} T^i 1 \simeq \lim_{i \in \omega^{\mathrm{op}}} T^{i + 1} 1 \simeq T(\lim_{i \in \omega^{\mathrm{op}}} T^i 1)$ gives $\lim_{i \in \omega^{\mathrm{op}}} T^i 1$ a coalgebra structure for $T$. Furthermore, $\lim_{i \in \omega^{\mathrm{op}}} T^i 1 \simeq T(\lim_{i \in \omega^{\mathrm{op}}} T^i 1)$ is a terminal coalgebra.

The statement of this result was adapted from this nLab article.

Remark. (Initial algebras map into terminal coalgebras)

Let $T : \mathsf{C} \to \mathsf{C}$ be an endofunctor with initial algebra $T\ i \xrightarrow{\texttt{cons}} i$ and terminal coalgebra $j \xrightarrow{\texttt{des}} T\ j$. Because $\texttt{cons}$ is an isomorphism, we have a coalgebra $i \xrightarrow{\texttt{cons}^{-1}} T\ i$. The universal property of the terminal coalgebra (i.e. corecursion) asserts the existence of a unique map $u := \texttt{corec}\ \texttt{cons}^{-1}$ such that $\texttt{des} \circ u = T\ u \circ \texttt{cons}^{-1}$. Equivalently, $T\ u = \texttt{des} \circ u \circ \texttt{cons}$. This map has thus far shown us how to include $\mathbb{N} ↪ \mathrm{co}\mathbb{N}$ and $\texttt{List}\ A ↪ \texttt{coList}\ A$.

Lemma. (Terminal objects have no proper quotient objects)

Let $j$ be the terminal object in a category $\mathsf{C}$, and let $\pi : j \twoheadrightarrow a$ be an epimorphism out of $j$. Then, $\pi$ is an isomorphism in $\mathsf{C}$.

The (dual of the) latter lemma, when specialised to initial algebras, described the corresponding structural induction schemas for inductive types. The specialisation to coinductive types should therefore be called coinduction. We will do a full specialisation to $\mathsf{C} := \mathbf{Set}$ soon, but first we will explore a simple (and useful!) special case.

Lemma. (Simple coinductive rule for proving that maps into terminal coalgebras are equal)

Let $j \xrightarrow{\texttt{des}} T\ j$ be the terminal coalgebra for an endofunctor $T : \mathsf{C} \to \mathsf{C}$ and let $f, g : a \to j$ be parallel arrows into $j$. Suppose that the coequaliser $\pi : j \twoheadrightarrow e$ of $f$ and $g$ exists in $\mathsf{C}$. Then, if $T\ \pi \circ \texttt{des} \circ f = T\ \pi \circ \texttt{des} \circ g$, we must have $f = g$.

Note that $a$ is not required to have a coalgebra structure $a \to T\ a$. Note also that this lemma works in an arbitrary category $\mathsf{C}$.

Example. (Simple coinductive rule for $\mathrm{co}\mathbb{N}$)

Let $f, g : A \to \mathrm{co}\mathbb{N}$, and denote the coequaliser of $f$ and $g$ by $[-] : \mathrm{co}\mathbb{N} \twoheadrightarrow (\mathrm{co}\mathbb{N} / f = g)$. The assumption $T [-] \circ \texttt{des} \circ f = T [-] \circ \texttt{des} \circ g$ in the previous lemma can be unpacked as follows:

  • Equivalently, show that for any $x \in \mathrm{co}\mathbb{N}$, we have $((1_{\{\text{no}\}} + [-]) \circ \mathrm{pred} \circ f) (x) = ((1_{\{\text{no}\}} + [-]) \circ \mathrm{pred} \circ g) (x)$.
  • Equivalently, show that for any $x \in \mathrm{co}\mathbb{N}$, both of the following hold: $\mathrm{pred}\ (f\ x) = \text{no}$ iff $\mathrm{pred}\ (g\ x) = \text{no}$; if instead $\mathrm{pred}\ (f\ x) =: y \neq \text{no}$ and $\mathrm{pred}\ (g\ x) =: z \neq \text{no}$, then $[y] = [z]$.
  • Equivalently, show that for any $x \in \mathrm{co}\mathbb{N}$, both of the following hold: $\mathrm{pred}\ (f\ x) = \text{no}$ iff $\mathrm{pred}\ (g\ x) = \text{no}$; if instead $\mathrm{pred}\ (f\ x) =: y \neq \text{no}$ and $\mathrm{pred}\ (g\ x) =: z \neq \text{no}$, then $y$ is related to $z$ under the equivalence relation defining the quotient $(\mathrm{co}\mathbb{N} / f = g)$.

The final part of the last bullet point above is interesting. The equivalence relation $\sim$ defining the quotient $(\mathrm{co}\mathbb{N} / f = g)$ is freely generated by the relationships $f\ a \sim g\ a$ for $a \in A$. Hence, showing that $y \sim z$ can effectively be done by working in a context where one assumes that $f\ a = g\ a$ for all $a \in A$ (thereby implicitly working in the quotient $(\mathrm{co}\mathbb{N} / f = g)$) and demonstrating that in this context, we must have $y = z$[5] [5] This is not a very precise statement. The precise version is to genuinely work in the quotient; draw the commutative diagram displayed above to help you remember the details you're working with!. In analogy to induction (where inputs to constructors come from an equaliser), one could call this a coinductive hypothesis.

We will give example applications of this proof method in an upcoming section on example coinductive proofs.

We now specialise the "terminal objects have no proper quotient objects" lemma to terminal coalgebras of endofunctors $\mathbf{Set} \to \mathbf{Set}$. Since quotients of sets are characterised by equivalence relations, the statement gives a rule for judging when an equivalence relation on a terminal coalgebra is the equality relation, and hence provides a way to prove that two elements of a terminal coalgebra are equal.

Lemma. (Coinduction in $\mathbf{Set}$)

Let $J \xrightarrow{\texttt{des}} T\ J$ be the terminal coalgebra for an endofunctor $T : \mathbf{Set} \to \mathbf{Set}$. Let $\sim$ be an equivalence relation on $J$ and denote by $[-] : J \to J / {\sim}$ the projection onto its quotient. Suppose that for all $x, y \in J$ with $x \sim y$, we have $(T [-] \circ \texttt{des}) (x) = (T [-] \circ \texttt{des}) (y)$. Then, $\sim$ is the equality relation on $J$; i.e. for all $x, y \in J$, $x \sim y \implies x = y$.

Example. (Bisimulation of streams)

Fix a set $A$, and let $\sim$ be an equivalence relation on $\texttt{Stream}\ A$ satisfying the assumptions of the previous lemma (with $T : X \mapsto A \times X$). Fix arbitrary $\mathrm{as}, \mathrm{bs} \in \texttt{Stream}\ A$, and write $\mathrm{pop}\ \mathrm{as} = (a, \mathrm{as}')$ and $\mathrm{pop}\ \mathrm{bs} = (b, \mathrm{bs}')$. The assumption on $\sim$ is that if $\mathrm{as} \sim \mathrm{bs}$, then $(a, [\mathrm{as}']) = (b, [\mathrm{bs}'])$; i.e. $a = b$ and $\mathrm{as}' \sim \mathrm{bs}'$. Such a relation $\sim$ is called a bisimulation on $\texttt{Stream}\ A$, and the lemma guarantees that the only bisimulation is the equality relation. Thus, to prove that two streams are equal, it suffices to construct a bisimulation which identifies them.

Bisimulations identify streams exhibiting the "same behaviour" — two streams have the same behaviour just when their heads are the same and their tails have the same behaviour. The lemma can be read as the statement that streams with the same behaviour are equal.

We will give an example application of this proof method in an upcoming section on example coinductive proofs.

We stress that coinduction is not the only proof method for terminal coalgebras. In particular, non-equality predicates are difficult to prove in this way. Much like how many statements about natural numbers have direct, non-inductive proofs, some statements about conatural numbers also have direct, non-coinductive proofs.
